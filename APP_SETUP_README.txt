PANKAJ COLDRINK TRADERS — APP VERSION (PWA)

This folder contains an installable Progressive Web App version of the website.

IMPORTANT: It is not an Android APK and is not published on Google Play. To install it as an app, first host ALL files in this folder on an HTTPS website. Then open the hosted website in Chrome on Android, tap the three-dot menu, and choose “Install app” or “Add to Home screen”.

The website's order form is still a preview and does not yet send orders to WhatsApp, email, or a database. Connect and test an order system before using it with customers. Prices, stock, delivery fees, and case quantities must be verified by your father before publishing.
